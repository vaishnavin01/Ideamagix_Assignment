# Ideamagix_Assignment# ART Gallery

A modern and responsive web-based gallery showcasing a variety of art styles from around the world. Built with HTML5, CSS3, JavaScript, jQuery, Bootstrap, and Owl Carousel.

---

## Features

1.Responsive Design: Works seamlessly on desktop, tablet, and mobile.
2.Image Carousel: Interactive slider powered by Owl Carousel with lazy loading.
3.Lazy Loading: Improves performance by loading images as needed.
4.Mobile Menu: Hamburger menu implemented using JavaScript for mobile screens.
5.nteractive Cards: Cards displaying types of art.
6.Page Loader: Full-screen loader with artistic gradient.
7.Footer with Social Links: Instagram, WhatsApp, Facebook icons.

---

## Art Types Displayed

- Abstract Art
- Modern Art
- Classic Art
- Digital Art

---

## Technologies Used

- HTML5, CSS3
- JavaScript, jQuery
- Bootstrap 5
- Owl Carousel
- Font Awesome (for social icons)
